# CDN-Optimized Asset Pipeline

---

## 1. Flat Output Structure

```
📁 wmo-icon-font/
├── 📁 src/
│   ├── 📁 svg-raw/        # Source of truth vectors
│   └── 📄 registry.json   # Provenance contract
├── 📁 scripts/
│   ├── 📄 build.ts        # Bun orchestration
│   └── 📄 svgo.config.js  # CDN minification rules
├── 📁 dist/               # Published to NPM
│   ├── 📁 svg/            # Minified SVGs for direct CDN linking
│   ├── 📁 fonts/          # woff2, ttf
│   ├── 📄 wmo-icons.css   # CSS classes
│   └── 📄 index.ts        # TypeScript enums
├── 📄 package.json
└── 📄 README.md           # Auto-generated by build
```

## 2. SVGO CDN Optimization

```javascript
// svgo.config.js
module.exports = {
  multipass: true,
  plugins: [
    'preset-default',
    'removeDimensions',     // Fluid CSS scaling
    'sortAttrs',            // Better gzip compression
    {
      name: 'removeAttrs',
      params: { attrs: '(stroke|fill|data-.*)' }, // Inherit color from UI
    },
  ],
};
```

## 3. Bun Orchestration Script

```typescript
// scripts/build.ts
import { $, file, write } from "bun";

const ORG_NAME = "@your-org/wmo-icon-font";
const CDN_BASE = `https://unpkg.com/${ORG_NAME}/dist/svg`;

console.log("1. Optimizing SVGs for CDN...");
await $`bunx svgo -f src/svg-raw -o dist/svg --config svgo.config.js`;

console.log("2. Compiling Font & TypeScript Contracts...");
await $`bunx fantasticon dist/svg -c .fantasticonrc.js`;

console.log("3. Generating README with Attributions...");
const registryText = await file("src/registry.json").text();
const registry = JSON.parse(registryText);

let readme = `# WMO Weather Icon Reference Contract\n\n`;
readme += `> DO NOT EDIT THIS FILE DIRECTLY.\n`;
readme += `> Auto-generated from \`src/registry.json\`.\n\n`;
readme += `## Asset Inventory & Provenance\n\n`;
readme += `| WMO Code | Condition | Asset ID | Author | Modified | CDN Link |\n`;
readme += `| :--- | :--- | :--- | :--- | :--- | :--- |\n`;

registry.icons.forEach((icon: any) => {
  const cdnUrl = `${CDN_BASE}/${icon.file}`;
  readme += `| **${icon.wmo_code}** | ${icon.description} | \`${icon.id}\` | ${icon.attribution.author} | ${icon.attribution.modified} | [View SVG](${cdnUrl}) |\n`;
});

readme += `\n## UI Integration (Svelte)\n`;
readme += `\`\`\`html\n<script lang="ts">\n  import { WmoIcons } from '${ORG_NAME}';\n</script>\n`;
readme += `<i class="wmo {WmoIcons.ClearDay}"></i>\n\`\`\`\n`;

await write("README.md", readme);

console.log("Pipeline Complete.");
```

## 5. `package.json` — Ship Only What's Needed

```json
{
  "name": "@your-org/wmo-icon-font",
  "files": ["dist", "README.md"]
}
```

CDNs handle edge caching automatically. Consumers can either import the font natively or inject SVGs directly from the edge cache via the generated CDN links.

# Project Ledger

Execution state, decisions, and evidence for the wx-font WMO weather icon font project. Agents: do
not start here — `AGENTS.md` (repo root) is the entry point, `control.yaml` is the router, and
`ledger.yaml` documents the routing tiers and directory contract. Humans: `roadmaps/` holds
status and next actions, `memories/` holds rationale (frontmattered cards, grep the `hook:`
lines), `logs/` holds append-only evidence.
